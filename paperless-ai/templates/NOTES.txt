IMPORTANT / LIMITATIONS
- This application is stateful and uses a first-start web wizard.
- It stores state in SQLite and related files.
- It must run as a SINGLE replica (replicas=1).
- Persistent storage is required for: /app/data

ACCESS
{{- if .Values.ingress.enabled }}
Ingress is enabled. Access your instance via the configured hostname(s).
{{- else }}
Ingress is disabled. You can access the UI using port-forward:

  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "paperless-ai.fullname" . }} 3000:3000

Then open:
  http://localhost:3000
{{- end }}

FIRST START
- Open the web UI and complete the setup wizard once.
- The generated configuration and SQLite DB will be stored on the persistent volume.

TROUBLESHOOTING
- If the pod is Pending due to PVC issues:
    kubectl -n {{ .Release.Namespace }} get pvc
    kubectl -n {{ .Release.Namespace }} describe pvc <pvc-name>
    kubectl get storageclass

- If you see errors like "EACCES bind tcp://10.x.x.x:3000":
  This may be caused by Kubernetes service env injection (*_SERVICE_HOST).
  Recommended: enableServiceLinks: false (chart should set this by default).
