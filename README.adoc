= paperless-ai-helm-chart

A Helm chart for deploying https://github.com/clusterzx/paperless-ai[clusterzx/paperless-ai] on Kubernetes.

== ⚠️ Disclaimer

Using this Helm chart is at your own risk.

Always back up your https://github.com/paperless-ngx/paperless-ngx[paperless-ngx] and your https://github.com/clusterzx/paperless-ai[paperless-ai] data before deploying or upgrading.

== Helm Chart (OCI)

=== Install from the OCI registry


[source,shell]
----
helm registry login ghcr.io
helm upgrade --install paperless-ai oci://ghcr.io/chilichonka/charts/paperless-ai
----

=== Get the default values

[source,shell]
----
helm show values oci://ghcr.io/chilichonka/charts/paperless-ai > values.yaml
----

Then edit `values.yaml` and install with:

[source,shell]
----
helm upgrade --install paperless-ai oci://ghcr.io/chilichonka/charts/paperless-ai -f values.yaml
----
